Super Kanban organizes DeepSeek Harness sessions into tasks so you can see what is running, what needs attention, and what is ready to review.

After enabling the plugin, open **Task board** from the sidebar. Use the full-page board to plan across workspaces, or switch to the side or floating board while you work in a session.

Tasks and project notes are stored locally. AI analysis uses the model selected in the board.
